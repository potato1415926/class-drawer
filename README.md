# Rollcall Picker · 班级点名抽人

一个单文件 HTML 的课堂随机点名工具。双击打开就能用，不需要服务器、不需要装任何东西。

![单文件](https://img.shields.io/badge/单文件-HTML-orange) ![无依赖](https://img.shields.io/badge/依赖-无-green)

## 简介

给老师上课抽人用的小工具。打开网页点「抽取」，名字滚动一段时间后停在一个人身上；支持一次抽多人、跳过动画、冷却防连抽、抽取记录和隐藏的权重调节。

## 功能

**抽取**
- 单抽 / 多抽：右侧「人数」输入框调人数，默认 1
- 两种动画：滚动文字、物理转盘（转盘有三档节奏：舒缓 / 标准 / 轻快）
- 跳过动画：随时跳到结果

**名单**
- 主界面右侧显示完整名单，被冷却的人置灰并显示剩余轮次或时间
- 逐个添加，也支持粘贴纯文本批量导入（换行、逗号、顿号都能分隔）
- 右键条目：临时提升、加冷却、解冷却、删除（手机上长按等同右键）

**冷却**
- 按轮次或按时间冷却，防止同一个人被连着抽到
- 支持无限冷却；关掉冷却开关后，已有的冷却数据仍保留

**记录**
- 记录最近一周的抽取，可以给每次抽取加备注
- 可以关掉「保存抽取数据」，关掉后主界面的记录按钮会隐藏

**权重（默认关闭）**
- 连续点击同一个名字 7 次，打开权重调节面板
- 连续点击左上角图标 5 次，打开两人之间的权重转移面板
- 权重只在转盘里体现：权重高的人在队列里出现更多次

**其他**
- 「最简化」：临时关掉冷却和权重，只按纯随机抽，关闭页面后自动恢复
- 备份导出 / 导入（JSON）
- 设置自动保存在浏览器本地，刷新不丢

## 第一次打开

默认名单是 30 个虚构名字。如果名单还是默认状态，每次打开都会弹一个欢迎框，可以选择：

1. **直接进入** — 不动任何设置
2. **导入已有备份** — 直接选择之前导出的 JSON
3. **进入初次设置引导** — 五页引导，依次设置名单、冷却、动画、数据保存、权重

导入自己的名单后，欢迎框就不再出现。

## 使用方法

1. 下载 `班级点名抽人.html`
2. 双击用浏览器打开（推荐 Chrome / Edge）
3. 在设置里导入名单，或者直接把名字加到右侧名单
4. 点「抽取」

## 数据存储

数据存在浏览器本地 localStorage，不会上传到任何地方。三个键：

| 键 | 内容 |
|---|---|
| `rollcall_app_v3` | 名单、冷却、设置、权重 |
| `rollcall_history_v1` | 抽取记录 |
| `rollcall_tempweight_v1` | 临时权重规则 |

注意：换浏览器、换电脑、清理浏览器数据都会丢。重要数据请用「导出备份」留一份 JSON。

## 浏览器要求

Chrome、Edge、Safari、Firefox 的较新版本都可以。手机也能用，窄屏会自动改成单列。如果浏览器不支持选择本地文件，「导入备份」按钮会置灰并提示。
